Description
Screenshot Gallery 삭제 기능 테스트 중 삭제 확인창을 열 때 deleteScreenshotConfirmWindow가 null로 처리되는 문제가 발생했다.

확인 결과 실제 사용하는 ScreenShotGallery 오브젝트 외에, IssueWindow 하위 ScreenShot 오브젝트에 테스트용 QAScreenshotGallery 컴포넌트가 추가로 남아 있었다.

연결되지 않은 테스트용 Gallery 인스턴스가 참조되면서 삭제 확인창 UI가 정상적으로 연결되지 않아 null 오류가 발생했다.

테스트용 QAScreenshotGallery 컴포넌트를 제거하고, 실제 사용하는 ScreenShotGallery 오브젝트 하나만 남기도록 정리했다.
